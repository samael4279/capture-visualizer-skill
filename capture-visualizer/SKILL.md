# Capture + фермы/Layher/риггинг — профессиональная шпаргалка

Отвечать по-русски. Пользователь — профессиональный художник по свету (grandMA2), азы не объяснять.
Основная версия — **Capture 2026** (`c:\program files\capture 2026\capture 2026.exe`).
Официальный мануал: https://capture.se/Manual/en-UK/2026/ (страницы: FileMenu, EditMenu, ViewMenu, DesignViews, DesignTab, FixturesTab, UniversesTab, MediaTab, LibraryTab, PerformanceTuning, Appendix). Новое в 2026: https://www.capture.se/Products/News-in-2026. При сомнении — свериться с мануалом.

## 1. Система координат (критично)
- **Y — вертикаль (высота).** X и Z — горизонтальная плоскость. Это не CAD-стандарт (там Z вверх) — не путать.
- Вид **Top** смотрит вниз по Y. **Front** — вид со стороны зрителя; в Top фронт (зал) — **низ экрана**. **Right** — вид сбоку.
- Rotation в Selected Items: **Y Rotation** — разворот в плане (вокруг вертикали). X/Z Rotation — заваливают объект.
- Position группы/объекта — центр габарита. Чтобы «поставить в ноль» в плане: X=0, Z=0, Y не трогать (иначе низ уйдёт под/над землю). Для низа на 0: Y = половина высоты.
- Если сцена из SketchUp изначально смотрит в +X, то чтобы смотрела во Front — **Y Rotation = −90°** (90° = задом к фронту). Всегда проверять по Top (барьер внизу) и Right.

## 2. Интерфейс
- 3 дизайн-вида (Alpha/Beta/Gamma) + панель Project с вкладками: Design, Fixtures, Universes, Media, Snapshots, Library.
- Design-категории: Project, Selected Items (свойства выделенного), Views, Layers, Filters (наборы слоёв+юниверсов, DMX-переключаемы до 255), Fixture Groups, Camera Positions, Scenes (Store/Recall, у объекта должно быть Include in Scenes), Materials (PBR), Gobos (512×512), Frame Lists, Custom Fixture Library (импорт IES), Symbols (SVG), Reports, Plot Styles, Plots.
- Режимы вида: Wireframe (Ctrl+W), Plot (Ctrl+E), Live (Ctrl+R), Custom (Shift+Ctrl+X).
- Камера: Swing to Top/Front/Right/Left = Ctrl+1/2/3/4, Swing to Selection Ctrl+5, **Focus Selection Ctrl+F**, **Focus All Shift+Ctrl+F**, Position 1–5 = Ctrl+6…0.
- Hidden Objects показать/скрыть: Shift+Ctrl+H (для активного вида). Grid Shift+Ctrl+G, Widgets Shift+Ctrl+W, Fixture Information Shift+Ctrl+I.
- Render Image (Ctrl+I) — полное качество, HDR (AVIF/EXR/PNG) или SDR; Save Image — быстрый снимок.
- Навигация: средняя кнопка мыши или Alt+ЛКМ — вращение/панорама; колесо — зум; Ctrl/Cmd при зуме — FOV.
- Развернуть панель/вид на весь экран — **двойной клик по заголовку** (кнопки в углу заголовка ненадёжны). Свойства в Selected Items прокручивать перетаскиванием полосы прокрутки справа (колесо там не работает).
- Раскладки окон: Window › Arrangements › Quad / Wide.

## 3. Выделение и правка
- Клик — выделить; Shift+клик — добавить; Ctrl+клик — переключить. Рамка слева→направо — только полностью попавшие; справа→налево — пересекающие. Двойной клик — войти в группу.
- Перетаскивание внутри красного габарита — двигать (Shift — ортогонально, Ctrl — без привязки). Красный треугольник — rotation anchor.
- Edit: Duplicate (Ctrl+D; кол-во + смещение X/Y/Z), Replace (Shift+Ctrl+R), Delete (Del), Group (Ctrl+G), Break Out of Group, **Break Group (Ctrl+B)**, Transform (Ctrl+T, relative/absolute), Align (Shift+Ctrl+A), Spread Even (Shift+Ctrl+V), Mirror (Ctrl+K), Position Rotation Anchor, Map Material (Ctrl+P), Model › (Hide distracting edges, lines→pipes, Polygon editor, drawing unit scaling), Sequential › (unit/circuit/patch/channel), Fixture Details (Shift+Ctrl+Enter), Focus (Ctrl+U), Unpatch, Measure (Ctrl+.; в Measure курсор показывает координаты — удобно снимать размеры).
- Edit › Select ›: By Layer, By Location, By Model, By Drawing Block Name, Motion Controlled, **Connected Truss** (выделяет всю собранную ферму из секций), Fixtures on Truss, By Fixture Type, By Fixture Group, By Cable Type. Инверсии выделения нет.
- Transform-диалог: доступность полей зависит от активного вида — легко повернуть не по той оси. Повороты надёжнее задавать в Selected Items › Geometry (X/Y/Z Rotation).
- Locked = Yes (например, у объектов из библиотеки-аттачментов) — Delete не работает, сначала Locked = No.

## 4. Импорт модели (File › Import Model)
Форматы: SKP, DWG/DXF (имена блоков сохраняются), 3DS, OBJ, glTF/GLB (PBR), MVR 1.4+, PDF (1-я страница), проекты Capture.
Порядок:
1. File › Import Model… → выбрать файл. Ошибки в логе вида «mirroring/scaling cannot be fully preserved» и «two-sided materials — only front face» — обычно некритичны → Continue.
2. Откроется окно-навигатор модели. **ДО перетаскивания** выставить внизу:
   - **Drawing unit**: для SketchUp-моделей в метрах — **1** (по умолчанию стоит 25,4mm = дюймы → неверный масштаб). Ввести и нажать Enter; признак — сетка навигатора станет мельче.
   - Include layers: All / None / Referenced / Referenced by Name. Layer grouping: None / By Source Filename / Keep. Filter.
3. Перетащить кнопку drag навигатора (третья из иконок под моделью) в дизайн-вид → меню **Place Here / Place at Original Position**.
4. Закрыть окно навигатора.
- Модель импортируется как группа(ы); теги SketchUp становятся слоями (в 2026 папки сохраняются как группы слоёв).

## 5. Рецепт: оставить только часть модели (например, сцену)
1. Выделить модель → Edit › Break Group (Ctrl+B).
2. Focus All, рамкой выделить нужную часть (сцену). Если захватились крупные чужие объекты — это нормально, разберёмся позже.
3. Selected Items › Hidden = Yes (временно спрятать нужное).
4. Focus All → рамкой выделить всё видимое → Delete (скрытые не выделяются).
5. Shift+Ctrl+H (показать скрытые) → удалить лишнее, попавшее в п.2, кликом по нему → выделить остаток → Hidden = No → Shift+Ctrl+H выключить.
6. Выделить всё → Ctrl+G (одна группа) → выставить Position/Rotation.

## 5a. Рецепт: ферма из библиотеки
- Library › Truss → фильтр (напр. `H30V`), галочка Section → тащить нужную секцию (H30V-L400 = 4 м) в вид. Осторожно: первая строка в выдаче может быть аттачмент (Box Attachment), а не секция.
- Секция по умолчанию лежит вдоль X; Y Rotation 90° — вдоль Z (по глубине). В Selected Items выставить Position (центр секции; Y центра = низ + ½ высоты сечения: H30 0,287 м, H40 0,387 м).
- Длинная ферма: Duplicate N шт со смещением = длине секции; потом Select › Connected Truss → Duplicate по другой оси для следующих линий.

## 6. Фикстуры, патч, юниверсы
- Fixtures tab — таблица-спредшит: мультивыделение, копипаст с Excel, сортировка, «=» (одинаковое значение) и «+» (инкремент), выбор колонок, группы вводом текста, колонки «#2» для второй точки патча, Pan/Tilt range overrides, индикаторы пересечения патча.
- Universes tab: номер — основной идентификатор (пропуски допустимы), Name опционален; патч через границу юниверса включён по умолчанию; режимы >512 каналов поддерживаются; Patch style Contiguous (1–2048).
- Export Fixture Data: CSV/TSV/Lightwright/XML, **grandMA2** (схемы слоёв: Project layers / Fixture types / Single), Hog 4. Import Fixture Data из CSV/TSV (сопоставление по Drawing name).
- Export Model: DWG/DXF, glTF/GLB, MVR 1.4 (геометрия + фикстуры/патч).
- Новое в 2026: Generic LED Strip (Bézier-редактор, пиксельное управление), Sling-объекты (нагрузки), Send to Production Assist (расчёт нагрузок), улучшенный дым (поглощает свет), lens flare, контраст/насыщенность.

## 7. Связь с пультом
- **grandMA2**: Art-Net (жёстко 2.x.x.x/10.x.x.x), **sACN** (полностью), **MA-Net2** (только Windows, gMA2 ≥2.9; Universes tab › Configure MA-Net..). Нужна железка MA (NPU, Command Wing, onPC node) — onPC без неё ничего не выдаёт; число юниверсов = сколько открывает железо. Talkback/фидбэк — только с железом.
- **grandMA3**: MA-Net3 через плагин (Options › Connectivity › Plugin Updater; версия плагина = версии MA3), нужна железка (консоль/wing/node/**viz-key**). Viz-key: до 262 144 параметров в Capture.
- ETC Eos — OSC (IP в Options), выбор каналов и pan/tilt-фидбэк. CITP: FSEL/CAEX/FPTC — синхронизация выделения и обмен патчем. Hog — свой драйвер.
- DMX Talkback (клик по фикстуре → pan/tilt в пульт) требует совпадения Channel в Capture и пульте.
- OSC в Capture: порт 4004, TCP/UDP.
- DMX-камера: каналы 1–12 (каталог, позиция, время, ambient, exposure), extended 13–14 — выбор фильтра/сцены.

## 8. Производительность
Главное — видеокарта и свежие драйверы. Дорого: число апертур (а не приборов), дым, прозрачные объекты, тени. Отключать Casts Shadows у неосвещаемого, Throws light у мультиапертурных «для вида». Тяжёлые импорты (5+ млн полигонов) — чистить лишнее.

## 9. Управление Capture на ПК пользователя (computer use)
- Доступ: computer_resolve_access(['Capture 2026']) → request_access (доступ протухает через 30 мин бездействия — запросить снова). Перед действиями — computer_open_application('Capture 2026').
- **Окно Claude на ПК перекрывает правую часть экрана** (на скриншотах его не видно, а клики туда не доходят: вкладки Snapshots/Library и всё правее ~930 px не реагируют). Перед работой попросить пользователя **свернуть окно Claude**; самому свернуть его нельзя (инструмент запрещает ввод в окно Claude).
- Если поверх открыт Chrome (или другое неразрешённое окно) — клики блокируются; попросить пользователя свернуть/закрыть его.
- Поле ввода иногда перекрывает чёрный прямоугольник (textinputhost) — значение не видно; проверять косвенно (по изменению сетки/модели) или зумом по полю после Enter.
- Файловые диалоги: печатать можно **только в поле «Имя файла»** (там же можно ввести путь папки + Enter для перехода, напр. `%USERPROFILE%\Downloads`, `D:\Projects`). Нельзя переименовать папку, нельзя кликать адресную строку. «Новая папка» создаётся, но переименовать её должен пользователь.
- Где лежат рабочие проекты — уточнить у пользователя; скачанное обычно в Загрузках (`%USERPROFILE%\Downloads`).
- Удобный приём: Escape/Deselect All перед новыми операциями; после серии действий — скриншот для проверки; в конце — computer_release_lock.
- Никогда не сохранять поверх без запроса; при сохранении сообщать полный путь.

# ЧАСТЬ II. ФЕРМЫ, LAYHER, РИГГИНГ

**Принцип ответственности:** мои расчёты — инженерная оценка для проектирования и проверки здравым смыслом. Финальные цифры — по **актуальной** таблице производителя конкретной фермы (Prolyte сейчас считает по EN 17115 / Eurocode; таблицы Black Book 2008 по DIN 4113 — только ориентир), а сложные/наружные/над людьми конструкции — подтверждает инженер-конструктор и ответственный риггер площадки. Всегда писать это одной строкой при выдаче расчёта. Расчёты делать в песочнице на Python (numpy), а не в уме; многопролётные балки — методом жёсткостей/трёх моментов.

Источники: Prolyte Black Book (https://paperclip.rcs.ac.uk/images/f/f0/Black_book.pdf), Prolyte Trusses User Manual Part 1 (prolyte.com › Support › Manuals), таблицы Prolyte «LOADING TABLE TRUSS TYPE … EN» (prolyte.com/getmedia/…), Layher Allround Technical Brochure / Instructions for Assembly and Use, EN 17115:2018, ANSI E1.2, BS 7905/7906, CWA 25, DGUV V17/18 (ex BGV C1), BGV D8/D8+.

## 10. Ферма: основы
- Сплав EN AW-6082 T6. Пояса (chords) Ø48–51 мм, раскосы (braces/diagonals). Серии Prolyte: **X** (лёгкие, пояс 51×2), **H** (усиленные, 48×3), **S** (крыши/большие пролёты: S36, S52, S66, S100). Профили: L — ladder (2 пояса), D — треугольник (3), V/T/R/F — квадрат/прямоуг. (4). Цифра — высота в см (30 = 290 мм, 40 = 390 мм).
- Соединения: конусные CCS (Prolyte: пин вставляется **снаружи внутрь**, широкая сторона отверстия наружу, зазор между фермами — так задумано, R-клипса перпендикулярно оси фермы, медный молоток), fork/pin (Global/Eurotruss FD), plated (болты, M12 = 25 Нм, M16 = 50 Нм, самоконтрящиеся гайки — одноразовые).
- Силы: изгибающий момент (верхний пояс сжат, нижний растянут), поперечная (shear — рядом с опорами и при тяжёлых коротких пролётах, рвёт раскосы/швы), продольная (башни, стропила — потеря устойчивости), кручение (односторонняя нагрузка, консоли, боковые кронштейны).
- Фермы с одно-/двусторонними раскосами (S36R, S52F/V, S66R/V, S100F) **не держат горизонтальных нагрузок** без инженера.
- Нагрев: алюминий теряет прочность — 100 °C → 85 %, 150 °C → 70 %, 200 °C → 50 %. Над мощными приборами в тропиках следить.

## 11. Таблицы нагрузок Prolyte
- Колонки: пролёт (м/ft) · **UDL** кг/м + прогиб · **CPL** (сосредоточенная в центре) + прогиб · **TPL** (2 груза в третях) · **QPL** (3 груза в четвертях) · **FPL** (4 груза в пятых). Значения TPL/QPL/FPL — **на каждую точку**.
- Таблица = однопролётная балка на двух опорах, статика, собственный вес фермы уже учтён, без консолей. Всё остальное — расчёт.
- Неравномерную/частичную нагрузку консервативно считать как CPL (всю сумму в центр).
- Человек на ферме = точечная нагрузка ≥ 1 кН (100 кг).
- Понижающие коэффициенты: **× 0,85** — износ (BS 7905-2, ANSI E1.2, EN 17115, CWA 25); **× 0,5** — если под нагрузкой люди и система не сертифицирована на «нагрузку над людьми» (принцип удвоения запаса); динамика подъёма **1,2–1,4** (быстрые/артистические движения — отдельный расчёт).
- Внутренние запасы Prolyte (старые таблицы): 1,7 до пластической деформации, 2,5 до разрушения; новые по Eurocode: γ = 1,35 собственный вес / 1,5 переменная.
- Прогиб: таблицы без лимита; по запросу L/100 или L/200. Пропорция: f₂ = f₁ · (Q₂ + G)/(Q₁ + G). Пример Black Book: X30D, 10 м, лимит L/200 → ≈ 14,25 кг/м с учётом 0,85.
- Ориентир (Black Book 2008, H30V): 10 м — UDL 110,5 кг/м (прогиб 104 мм), CPL 552 кг (83 мм), TPL 414 кг/т., QPL 276 кг/т., FPL 229 кг/т.; 1 м — UDL 1984 кг/м. Перед реальной работой брать текущий PDF таблицы.
- Вес секций (библиотека Capture): H30V-L400 ≈ 23,8 кг; H40V-L400 ≈ 25,9 кг.
- Перевод: 1 lb = 0,4536 кг; 1 м = 3,28 ft; 1 кН ≈ 102 кг (на практике 100).

## 12. Правила конструирования
- Грузы и точки подвеса — **в узлах** (пересечение раскоса с поясом) или вплотную. Крупный груз между узлами — запрещено без расчёта.
- Нагружать оба нижних пояса равномерно (иначе кручение, не учтённое в таблицах). Прибор на боковом кронштейне — кручение.
- **Консоль ≤ 1/6 основного пролёта** (правило Prolyte). На консоли — проверять отрыв (uplift) дальней опоры.
- Многоопорная (неразрезная) балка: статически неопределима, над внутренними опорами момент меняет знак (верх растянут). Распределение зависит от высот моторов — без load cell реальные нагрузки могут сильно отличаться от расчёта.
- Углы (corner blocks/сварные углы): держат ≈ **50–100 %** нагрузки примыкающих ферм; по умолчанию брать 50 % от CPL короткого пролёта. Точку подвеса — у угла.
- Круги: горизонтальный круг — **минимум 3 точки**; на 2 точках неустойчив. Наклонные круги — только инженер. Круг держит меньше прямой фермы.
- Ladder-ферма: поднимать только за **верхний** пояс, грузить только **нижний**, верхний раскреплять (боковая потеря устойчивости).
- Башни (towers): отказ — потеря устойчивости; расчётная длина sk = β·h (β = 2,5 для типичной ground support башни). Пример Black Book: H30V, h = 6 м → ≈ 1500 кг сжатия. Ground support: только по мануалу системы (ballast, outriggers, ветровые лимиты, sleeve block, ровное основание, проверка после нагружения).
- Пролёты делать равными, моторы — симметрично. Самый тяжёлый элемент (экран, PA) — отдельные точки, а не на световую ферму.
- **Прериг**: ферма, уложенная сверху на сценический конструктив (Layher/ферменную раму) как балка-колосник; к ней цепляются моторы, на моторах — софиты. Прериги идут по глубине сцены, софиты — поперёк. Вынос прерига за опору — консоль (≤ L/6, иначе крепить задний конец от отрыва).
- Сцена/помост (EN 13814): 7,5 кН/м² (750 кг/м²), прогиб L/200, точечная 7 кН на 5×5 см, горизонтальная — 10 % от вертикальной; перила публичные 100 кг/м на 1 м, сценические 30 кг/м.

## 13. Строповка
- Только за **основные пояса**, не за коннекторы и раскосы; обхват **минимум 2 поясов**; у узла; точка подвеса — над центром тяжести.
- Мягкие стропы с негорючим сердечником (Steelflex/Soft Steel) — стандарт. Полиэстер — до 100 °C (у PAR рядом 140–260 °C) → требуется стальная страховка. Трос по алюминию без защитного рукава — нельзя.
- Основные схемы: direct hitch (бракет/точка), choke hitch (2 одинаковые стропы), basket, multi-leg. Бракеты/клампы — только вертикальная тяга.
- Сталь + вертлюг/скоба (shackle): WLL каждого элемента ≥ нагрузки точки.
- Не «бамповать» моторами; при подъёме — визуальный контроль всей траектории; на рабочей высоте проверить соединения.

## 14. Моторы (цепные лебёдки)
- **BGV D8**: подъём при пустой зоне под грузом; висеть над людьми — только со вторичной страховкой (safety steel).
- **BGV D8+**: запас удвоен (номинал фактически ½), двойной тормоз — можно статично держать над людьми без страховки; двигать над людьми нельзя.
- **BGV C1 (DGUV V17/18)**: движение над людьми; запас 10:1, 4 концевика (2 рабочих + 2 аварийных), контроль провиса цепи, контроль нагрузки, двойной тормоз.
- Типовые WLL: 250 / 320 / 500 / 1000 / 2000 кг; скорость 4 м/мин (бывает 8/16/24); ПВ M2 = 40 %.
- Нагрузка на точку площадки = реакция фермы + доля веса фермы + вес мотора + вес цепи (+ бридель). Для motor-down лебёдка висит на ферме — её вес идёт в ферму. Динамика ×1,2.
- SWL системы = min(сумма WLL моторов, WLL фермы на пролёте) − собственный вес. Пример Black Book: H30V 4 м, 2×500 кг → ≈ 975 кг полезной.
- Load cells при многомоторных/неразрезных системах — обязательная рекомендация.
- IP54 — не для ливня, снаружи — накидки.

## 15. Формулы (вес в кг, длины в м)
**Однопролётная балка, пролёт L:**
- Точечный груз P на расстоянии a от A: R_A = P·(L−a)/L; R_B = P·a/L; M_max = P·a·(L−a)/L.
- Равномерная q (кг/м): R_A = R_B = qL/2; M_max = qL²/8. CPL: M = PL/4.
- Несколько грузов — суперпозиция (сумма по каждому).
- Консоль c за опорой B, груз P на конце: R_B = P·(L+c)/L; R_A = −P·c/L (**отрыв** — A должна удерживаться весом/второй точкой).
**Неразрезная балка, равные пролёты L, равномерная q:**
- 2 пролёта (3 опоры): 0,375 · 1,25 · 0,375 (× qL) → средний мотор берёт 62,5 % от q·2L.
- 3 пролёта (4 опоры): 0,4 · 1,1 · 1,1 · 0,4.
- 4 пролёта (5 опор): 0,393 · 1,143 · 0,929 · 1,143 · 0,393.
- Неравные пролёты/точечные грузы — считать численно (метод жёсткостей) в Python.
**Бридель** (две точки балки на одной высоте, расстояние D; апекс ниже на V; горизонтальные расстояния от апекса до точек d₁ и d₂, d₁+d₂ = D):
- Длины ног: L₁ = √(d₁² + V²), L₂ = √(d₂² + V²).
- Натяжения: T₁ = W·d₂·L₁/(V·D); T₂ = W·d₁·L₂/(V·D).
- Горизонтальная сила на балки: H = W·d₁·d₂/(V·D).
- Симметричный: T = W·L_ног/(2V). Угол между ногами 120° → каждая нога = W; держать ≤ 90° (≈ 0,71 W), лучше ≤ 60°.
- Точки на разных высотах — решать векторно (равновесие в апексе) в Python.
- Длина ноги для заданного апекса = геометрическая длина − длина железа (скобы, кольцо, мотор-хук).

## 16. Layher Allround (сценические конструкции, PA/FOH-башни, трибуны)
- Узел — **розетка** через каждые 0,5 м на стойке: 4 узких отверстия (ригели строго под 90°, автоматическое центрирование) + 4 широких (любые углы, диагонали); до 8 присоединений на уровне. Клин забивать молотком 500 г **до отскока**.
- Стойки 0,5–4,0 м (с впрессованной втулкой). Ригели системных длин: 0,25–4,14 м (типовые 0,73 · 1,09 · 1,40 · 1,57 · 2,07 · 2,57 · 3,07 · 4,14). **O-ригель** (трубчатый), **U-ригель** (под настилы U), усиленные U.
- **Решётчатые балки** (U и O lattice girders) высотой 0,5 м: 2,07 · 2,57 · 3,07 · 4,14 · 5,14 · 6,14 (O — до 7,71) м — для больших пролётов сцены/крыши.
- Диагонали — по длине поля и высоте (обычно 2,0 м): 0,73…4,14 м. Связи — «каждое 5-е поле» или башенным способом; уровни настилов ≤ 2,0 м.
- Базовые домкраты (**ZB / домкрат 60, 80**) + **стартовый элемент** (base collar) — первым на домкрат. Вылет винта: домкрат 60 — до ~15 см (сплошной до 39 см), домкрат 80 — до 51 см; чем больше вылет, тем меньше несущая.
- Ориентиры (Technical Brochure 2017, рабочие нагрузки): стойка K2000+ ≈ 26 кН (6 м, 3×2 м, без ветра); O-ригель 0,73 — 22,1 кН/м или 7,4 кН точечно; U-ригель 0,73 — 19,0 кН/м / 6,1 кН; U-решётчатая 2,57 — 12,5 кН/м / 26,6 кН в центре; O-решётчатая 2,57 — 12,7 кН/м / 26,7 кН; домкрат 60 при 0 вылете — 39 кН; домкрат 80 — 54 кН. Узел (Z-8.22-64): N = ±31 кН на ригель. Точные значения — по допуску DIBt Z-8.22-64/-939 и таблицам конкретной конфигурации.
- Типовые термины в SketchUp-моделях Layher (слои AR/TR/ZB): «AR Стойка 2.0/3.0» = стойка; «AR О-Ригель 2.07» = O-ledger; «AR U-Балочный 2.07» = U-ригель; «AR U-Ферма 2.07x0.5» = U-решётчатая балка; «AR Диагональ 2.07x…»/«TR Диагональ» = диагональ поля; «AR Стартовый элемент» = base collar; «ZB Домкрат 60» = базовый домкрат; «LAYHER PATAS» = опоры; «тр Гн 60x4» = профтруба/гнутый профиль.
- Layher event-системы: Event Floor T16 (настил), PA-Tower Plus, FOH-Tower, Video Wall System, трибуны, Protect-System, Event-крыши.

## 17. Порядок работы: «спроектировать ферму и посчитать точки»
1. Собрать нагрузки: вес приборов с клампами/страховками, экраны, PA, кабель (оценить погонно), декор. Источник веса — библиотека Capture/даташиты.
2. Задать пролёты и выбрать тип фермы по таблице × 0,85 (× 0,5 над людьми без сертификации). Проверить прогиб под задачу (кулисы/экраны — жёстче, L/200).
3. Расставить точки в узлах, пролёты равные, консоли ≤ L/6, углы — с точками рядом.
4. Посчитать реакции (п.15, Python) + вес фермы/моторов/цепей, ×1,2 динамика → сравнить с WLL мотора, бриделя, точки площадки. Бридели — длины ног и натяжения.
5. Выдать таблицу точек: №, X/Y/Z (в Capture Y — высота; на плане площадки — X/Z), нагрузка, мотор (WLL, класс D8/D8+/C1), бридель (D, V, L₁, L₂, T₁, T₂).
6. В Capture: фермы — из Library (динамические Prolyte и др.), точки — Rigging points / Sling-объекты с нагрузками, отчёт Reports; при наличии — Send to Production Assist.
7. Одной строкой: расчёт оценочный, финальное подтверждение — инженер/риггер площадки, таблица производителя актуальной редакции.

## 18. Осмотр и отбраковка (Prolyte User Manual)
- Пояс: трещины; изгиб > 3 мм между узлами; овальность > 5 % Ø; потеря стенки от царапин > 25 %; вмятина глубже толщины стенки; коррозия.
- Раскосы: трещины; смещение > L/300 или 3 мм (что меньше); потеря стенки > 25 % / сечения > 10 %; овальность > 5 %.
- Коннекторы: овальный износ отверстия пина > 10 % Ø; трещины сварки «труба–коннектор»; забоины > 2 мм глубиной и > 10 мм длиной.
- Пины/болты: грибок, заусенцы; деформированное отверстие под R-клипс; самоконтрящиеся гайки — однократно.
- Геометрия секции: скручивание > 0,15°/м; прогиб > 3 мм (L < 2250 мм) или > L/750.
- Осмотр — перед каждым использованием; формальная проверка компетентным лицом — минимум раз в год (чаще при уличной/солёной/песчаной эксплуатации).

**Важно:** публичных техпаков с точными цифрами мало, а реальные значения меняются. Ниже — подтверждённые данные (с источником) + типовые отраслевые диапазоны (помечено «типично»). Для конкретного шоу всегда запрашивать **актуальный техпак/rigging plot площадки** и согласование нагрузок с её главным риггером.

## 19. Как читать техпак площадки (риггинг)
- **High steel / low steel** — низ верхних и нижних балок кровли; **trim** — макс. высота низа подвешенного (обычно high steel − длина бриделя − мотор − ферма). **Grid** — фиксированная решётка (катвоки/балки) с точками.
- **Point load** (на точку/узел), **beam/truss load** (на балку целиком), **total roof load** (вся кровля/зона над сценой), допускаются ли **bridles** и под каким углом, **dead hang** vs bridle, только узлы (node/panel points).
- Политика: house riggers обязательны (union/штатные), утверждение rigging plot до загрузки, обязательные **load cells** на неразрезных/многомоторных системах, 2-я страховка (safety steel), запрет на точки в определённых зонах (табло-куб, кровельные фермы без узлов).
- Электрика под свет: обычно 3–6 × 400 А (3ф) у сцены + отдельные вводы под видео/звук; у арен США — CamLok, у Европы — Powerlock/CEE 125–400 А.
- PLASA ICOPER: rigging plot с датумом и декартовыми координатами точек, нагрузками (вкл. динамику); системы с 4+ точками — статически неопределимы → мониторинг нагрузки; вторичная страховка ≥ по ёмкости основной, натянута без провиса.

## 21. Штатный свет площадок (house rig)
- **Арены**: штатно только спортивный свет (LED-прожекторы, дим/без дима) + **followspots** в фиксированных позициях на катвоках (пример Broadmoor: 6×Super Trouper 2 кВт + Gladiator 2,5 кВт; NEC — 4×Robert Juliat 2,5 кВт HMI в кабинах над задними рядами). Концертный свет почти всегда **везёт тур или прокатчик**; иногда есть базовый пакет (Broadmoor: 10 секций box truss с 6×PAR64).
- **Концертные залы/театры**: полноценный штатный рисунок. Пример — **Barbican Hall** (Лондон): пульт grandMA2 light + wing, replay unit, NPU; 64 ETC D60 Lustr+ (оркестровый, фикс.), профили ETC S4 и RJ 611/614, движущиеся: 12 Claypaky B-EYE K20, 30 B-EYE K10, 8 Mac Viper Profile, 13 Robe Pointe, 13 Robe DL4S, 6 Mac 700, 12 ADB Warp/M, 6 SolaFrame; позиции: нумерованные штанги (Bar 1…7), штанги зала, стены, FOH, пол.
- **Клубы/залы 1–5 тыс.**: типично 1–3 фермы над сценой + задник: 8–24 голов (spot/beam/wash), LED-PAR/бары, стробы, блайндеры, дым/хейзер, иногда 1–2 пушки; пульт MA2/MA3, ChamSys, Avolites. Перед офером всегда сверять «что есть в доме» с райдером.

## 22. Типовые туровые развесы
**Арена (end stage), стандарт:**
- **Mother grid** (рама 2–4 т/точку) на 20–40 моторах по 2 т → внутри на 1-тонниках висят свет/видео/пушки. Пример Ed Sheeran ÷: веерный грид на 30×2 т, внутри 50×1 т, свет+видео ≈ 38 т (без звука), PA — по 2×2 т + 8×1 т на сторону; всего 104 мотора; выгрузка через 45 мин после посадки грида. Load cells на всех точках грида.
- Без грида: 4–6 продольных/поперечных ферм (DS, MS, US, side), экран апстейдж, PA L/R + сабы/фланги, delay-кластеры. Чаще всего 60–120 моторов.
- **Автоматика** (Kinesys, TAIT Navigator, Movecat): подвижные поды/ромбы/рамы 8–16 м. Пример Chris Brown: 2 пода (5×3 м HSL low profile), каждый 6×6 Elation SIXPAR 200 + 16 Sharpy по периметру; 8× Kinesys Elevation 1+ с 1-т Liftket 12 м/мин; всего ~100 моторов.
- Свет: споты/профили на фермах + ряд beam'ов, wash по фронту, ладдеры/боковые стойки (кросс-свет), полы (floor packages), блайндеры/стробы/LED-бары, 4–8 пушек (часто truss spots в US-ферме + house spots), камеры-фронталы для ТВ.
- Объём: арены 2020-х — 200–600 приборов, 6–20 юниверсов (больше с пиксельными), MA3/MA2 + бэкап.
**Театральный/«дивный» развес (поп-вокал, мюзикл-тур):** 5 электрик + апрон + боковые позиции + FOH-ферма; пример Bette Midler: 42 x.Spot, 130 wash (Studio Beam за порталом, Mac 2000 даунстейдж), 10 cyc-приборов, шинбастеры на полу, пушки + тросс-споты. Пример Sarah Brightman: круг 70 ft над сценой + серия кривых ферм + прямая 35 ft по оси.
**Стадион:** своя конструкция (крыша/ворота/арка) + delay-башни как световые позиции + мостики/B-stage. Пример Coldplay MOTS: 74 Ayrton Perseo (24 на арке над экраном-«луной», 48 на delay-башнях FOH), 66 Domino S (24 на полу апстейдж, 10 боковые с пилонов, 32 по апрону и сателлитам), Claypaky Xtylos на арке, Chauvet Strike M — кольца стробов вокруг сцен; всё IP65.
**Фестиваль:** крыша площадки с «домашним» пакетом (фронт-ферма, 3–5 ферм, ладдеры, задник) + head-liner floor package/свои поды на автоматике; рабочее окно смены 15–30 мин → всё на тележках/дольках.

## 23. Чек-лист перед развесом на чужой площадке
1. Техпак + rigging plot (high/low steel, точки, нагрузки, бридели, зона табло).
2. Сравнить суммарный вес шоу (свет+видео+звук+моторы+кабель) с лимитом зоны, разложить по точкам (п.15).
3. Trim: high steel − бридель − мотор (≈0,6–1 м при motor-down) − ферма − приборы ≥ нужная высота; учесть клиренс экрана/PA.
4. Питание и места под дим/дистро, кабель-трассы до FOH, позиции пушек.
5. House rig: что есть, что убрать (спорт-свет — гасится/дим?), куда встают пушки.
6. Согласовать с главным риггером площадки, отдать plot с координатами (датум, X/Y), нагрузками и типом моторов.
